- Long-press a conversation to leave a group DM or close a one-to-one chat. A closed chat comes back on its own the moment the other person writes again.
- Server settings gained a description field, an icon you can upload from your phone, and the full audit log.
- Attachment previews appear as soon as you pick a file instead of waiting on validation, and files shared from OrangMove now preview and download properly.
- The typing indicator no longer sends a packet per keystroke.
- Losing your connection no longer looks like being signed out.
- You can now set a custom app icon from Appearance. Android keeps its own launcher icon, so the change shows up in the web and desktop apps.
- The app tells the server which version it is, so a build too old to talk to the server can say so instead of failing at random.
